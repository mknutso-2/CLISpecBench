513 - Type of Report and Period Covered Note (R)

Subfield Codes
$a - Type of report (NR)
$b - Period covered (NR)
$6 - Linkage (NR)
$8 - Field link and sequence number (R)

FIELD DEFINITION AND SCOPE

Information on the type of report and the period covered by the report.

GUIDELINES FOR APPLYING CONTENT DESIGNATORS

■ INDICATORS

  • Both indicator positions are undefined; each contains a blank (#).

■ SUBFIELD CODES

$a - Type of report
Type of report (e.g, annual report, interim report).
513 ##$aInterim report;$bJan.-July 1977.
$b - Period covered
Dates indicating the period covered by the report.
513 ##$aQuarterly technical progress report;$bJan.-Apr. 1, 1977.
$6 - Linkage
See description of this subfield in Appendix A: Control Subfields.
$8 - Field link and sequence number
See description of this subfield in Appendix A: Control Subfields.

INPUT CONVENTIONS

Punctuation - Field 513 ends with a period unless another mark of punctuation is present. Subfield $a ends with a semicolon if followed by subfield $b.
