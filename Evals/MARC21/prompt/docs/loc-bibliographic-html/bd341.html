FIELD DEFINITION AND SCOPE

Information about modes of access to the content of a resource, including its primary mode of access and alternative mode(s) of access or accessibility features.

GUIDELINES FOR APPLYING CONTENT DESIGNATORS

■ INDICATORS

First Indicator - Application

# - No information provided

0 - Adaptive features to access primary content

Adaptive features to access primary content of a resource.

1 - Adaptive features to access secondary content

Adaptive features to access secondary content of a resource.

Second Indicator - Undefined

Undefined and contains a blank (#).

■ SUBFIELD CODES

$a - Content access mode

Mode required to access the content of the resource without using assistive features (for example, textual, visual, auditory, tactile, mathOnVisual).

Field 341 - Accessibility Content [REDESCRIBED, 2024]
Field definition and scope was broadened in order to accommodate the recording of all accessibility features of a resource. The change also applies to the definitions of subfields $a and $2.
