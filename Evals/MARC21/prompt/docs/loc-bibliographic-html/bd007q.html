007 - Notated Music (R)

MARC 21 Bibliographic - Full
October 2000
Indicators and Subfield Codes
Field has no indicators or subfield codes; the data elements are positionally defined.
Character Positions
00 - Category of material
q - Notated music

01 - Specific material designation
u - Unspecified
| - No attempt to code		  

FIELD DEFINITION AND SCOPE

When field 007/00 contains code q, it contains special coded information that identifies the item physically as a notated music.

GUIDELINES FOR APPLYING CONTENT DESIGNATORS

■ CHARACTER POSITIONS

00 - Category of material
q - Notated music
One-character alphabetic code that indicates the category of material to which the item belongs is notated music, which is defined as graphic, non-realized representations of musical works, both in printed and digitized manifestations. It includes musical scores and/or parts, diagrammatic representations, tablature, instructions for chance compositions, pictures or paintings intended as musical compositions, square note notation, klavarskribo, chant notation, neumes, braille, and other ways of representing the four components of musical sound: pitch, duration, timbre, and loudness. Notated music is often the means for communicating to the performer(s) how the musical work notated therein is to be realized in sound. A fill character (|) is not allowed in this position.
01 - Specific material designation
Special class of textual material to which an item belongs.
u - Unspecified
Special material designation for the notated music is not specified.
| - No attempt to code

■EXAMPLE

007 qu
[Item is a notated music (007/00)]

INPUT CONVENTIONS

Field length - For the category of material notated music, field 007 should consist of two character positions.
