FIELD DEFINITION AND SCOPE

Detailed information relating to the availability of items from publishers.

Used primarily by book trade users of the MARC format.

GUIDELINES FOR APPLYING CONTENT DESIGNATORS

■ INDICATORS

  • Both indicators are undefined; each contains a blank (#).

■ SUBFIELD CODES

$a - Publishers' compressed title identification
Sufficient title-centered bibliographic information to identify a product, according to conventions of the originating agency.
$b - Detailed date of publication
Detailed date of publication of the item. It is recorded in the format yyyymmdd in accordance with ISO 8601, Representation of Dates and Times. The "mm" and "dd" positions contain zeroes when the data is unknown.
366 ##$aSteinberg Adolescence (3rd ed)$b19921200
[Item published in 1992]
$c - Availability status code
Two-digit status code followed after a space by the date of the status report. The date is recorded in the format yyyymmdd in accordance with ISO 8601, Representation of Dates and Times. The source of the availability code is recorded in subfield $2.
366 ##$b19960517$cNP 19951205$2onixas
[Not yet published as of 5th December 1995; due 17th May 1996]
$d - Expected next availability date
Detailed date for publication of the item. It is recorded in the format yyyymmdd in accordance with ISO 8601, Representation of Dates and Times. The "mm" and "dd" positions contain zeroes when the data is unknown. Subfield $d is used when subfield $c indicates whether the product is not yet published, being reprinted, not yet in stock, is being remaindered, or is temporarily unavailable.
366 ##$cRP 19951205$d19960600
[Reprinting, as of 5th December 1995; new stock expected in June 1996]
$e - Note
Free text note.
$f - Publisher's discount category
Coded information concerning the category of discount offered by the publisher. The first character position identifies the source of the code, character positions 2-5 identify the source of supply and characters 6-8 identify the discount group. For example, the category "ANIEL122," identifies the source of the code as Book Industry Communications, the source of supply to Nielson Bookdata and the discount group 122.
$g - Date made out of print
Date when the product became out of print. The date is recorded in the format yyyymmdd in accordance with ISO 8601, Representation of Dates and Times. The "mm" and "dd" positions contain zeroes when the data is unknown.
366 ##$cOP 20011105$g20011013$jUK$2onixas
[Item that went out of print in the UK in October 2001. The status was changed on 5th November 2001]
$j - ISO country code
Code for the country in which the information in the field is applicable.
Code from: ISO 3166-1, Codes for the Representation of Names of Countries.
$k - MARC country code
Code for the country in which the information in the field is applicable. Code from: MARC Code List for Countries.
$m - Identification of agency
Identification of the agency supplying the information in the field.
$2 - Source of availability status code
MARC code that identifies the source of the availability status code recorded in subfield $c. Code from: Availability Status Code Source Codes.
$6 - Linkage
See description of this subfield in Appendix A: Control Subfields.
$8 - Field link and sequence number
See description of this subfield in Appendix A: Control Subfields.
