Appendix G - Format Changes

MARC 21 Bibliographic
December 2025

This section is provided for the lists of format changes that accompany each update to the MARC 21 Format for Bibliographic Data.

MARC 21 FORMAT FOR BIBLIOGRAPHIC DATA

FORMAT CHANGE LIST

Update No. 41, December 2025
This page documents the changes contained in the forty-first update to the 1999 edition of the MARC 21 Format for Bibliographic Data. Update No. 41 (December 2025) includes changes resulting from proposals that were considered by the MARC 21 community since the publication of Update No. 40 (June 2025).

Format changes in previous updates can be found on the MARC Format Overview page.
UPDATE 41 CHANGES
■ New content designators:
Subfields
$i Relationship information (R) in 381 (Other Distinguishing Characteristics of Work or Expression)
$z Title statement context note (NR) in 245 (Title Statement)
$4 Relationship (R) in 381 (Other Distinguishing Characteristics of Work or Expression)

■ Changes in content designator names and definitions:
Subfield
$c Statement of responsibility, etc. redescribed in 245 (Title Statement)
Appendix
JData Provenance Subfields: Data Provenance Code List moved to https://www.loc.gov/standards/valuelist/dataprov.html. New codes bcp47 and dpets added.

■ Fast-track changes:
New Subfields
$6Linkage (NR) in 060 (National Library of Medicine Call Number)
$6Linkage (NR) in 070 (National Agricultural Library Call Number)
New Codes
r - Remote sensing image in Maps 008/25 (Type of cartographic material) (006/08)
t - 4K Ultra HD Blu-ray in Videorecording 007/04 (Videorecording format)
Subfields
$d Groove characteristic redescribed in 344 (Sound Characteristics)
$g Conversion date renamed Conversion date/time and redescribed in 884 (Description Conversion Information)

Code
s - Blu-ray disc redescribed in Videorecording 007/04 (Videorecording format)

UPDATE 41 LOCAL PRINT GUIDE

The following sections and fields were created/changed in Update No. 41 and should be printed to keep a print copy of the format up-to-date. Changes appear in red.

  • 008 - Maps

  • 060 - National Library of Medicine Call Number

  • 070 - National Agricultural Library Call Number

  • 245 - Title Statement

  • 344 - Sound Characteristics

  • 381 - Other Distinguishing Characteristics of Work or Expression

  • 884 - Description Conversion Information

  • Appendix J - Data Provenance Subfields
