# LAS 1.4 prompt docs

This directory contains the official LAS 1.4 specification corpus used for the
LAS eval.

- `17-030r1.pdf` is the authoritative OGC LAS 1.4 specification PDF.
- `17-030r1-layout.txt` is a local text extraction of the same PDF that
  preserves line order and approximate layout to make the document easier to
  search in plain-text tooling.

When there is any discrepancy, the PDF is authoritative.
