I write academic papers in LaTeX, and every paper I submit gets formatted through BibTeX: I give it a database of references (a `.bib` file), a style file written by the journal (a `.bst` file, in BibTeX's little stack-based programming language), and a list of the citation keys my paper actually uses, and BibTeX produces the formatted reference list (a `.bbl` file) that LaTeX inlines. I'd like a command-line tool that does the same job BibTeX 0.99c does: reads the database, executes the style file's program against my cited entries, and writes a `.bbl` file that matches BibTeX's output — line-wrapping at 79 columns, name parsing correctly split into First/von/Last/Jr, `@string` macros resolved, `crossref` inheritance applied, and every `.bst` built-in function (the 37 operators the style language uses — string manipulation, name formatting, sort keys, `write$`/`newline$` for output, `if$`/`while$` for control flow, etc.) behaving exactly as BibTeX 0.99c does.

I want this to be a drop-in replacement for the stylistic behavior of BibTeX 0.99c: fed one of the canonical reference styles (`plain.bst`, `alpha.bst`, `unsrt.bst`, `abbrv.bst`) against a real `.bib` database, the `.bbl` file your tool produces should match the `.bbl` that the historic BibTeX binary would produce, byte-for-byte. The documentation in `docs/authoritative/` contains Patashnik's original sources — *BIBTEXing* (`btxdoc.tex`, the user guide), *Designing BibTeX Styles* (`btxhak.tex`, the style-language guide), the complete `bibtex.web` literate-Pascal source (the ultimate authority on built-in semantics, stack discipline, and output-buffer behavior), and the four reference styles themselves. **These are the authoritative specification.** The `docs/summary.md` is a reading index that helps orient an implementer — useful as a starting point, but the authoritative documents govern behavior when they disagree. I also want a structured JSON log summarizing what happened: which entries were found, which macros were defined, any warnings.
